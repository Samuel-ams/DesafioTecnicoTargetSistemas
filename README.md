# DesafioTecnicoTargetSistemas

## Projetos

### 01 — Controle de comissões

Calcula e apresenta as comissões dos vendedores a partir dos dados em
`src/01/vendasTimeComercial.json`. A comissão varia conforme o valor de cada venda.

### 02 — Controle de estoque

Apresenta os produtos e registra movimentações de entrada ou saída, atualizando
as quantidades e o histórico armazenados em `src/02/estoque.json`. O arquivo
`src/02/estoque.example.json` contém os dados de referência para inicialização.

### 03 — Calculadora de juros compostos

Calcula os juros compostos de um valor vencido, considerando uma taxa de 2,5% por
dia de atraso, e apresenta os juros e o total atualizado.
